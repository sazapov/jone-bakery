# Jone Bakery

A bakery application built with Flutter and Firebase.

Jone Bakery is a mobile application project designed around a bakery concept, with a clean and attractive user interface.

> 🚧 **Project Status: Work in Progress**
>
> This project is currently under development. More features and improvements will be added.

## Tech Stack

- **Flutter** – UI Framework
- **Dart** – Programming Language
- **Firebase** – Backend Services

## Project Overview

Jone Bakery is a personal development project created to explore Flutter application development, UI design, and Firebase integration.

## Development Goals

- Develop a clean and user-friendly interface
- Explore Flutter application architecture
- Integrate Firebase services
- Improve functionality and user experience
